About this reader

Enhanced reading uses pretrained PP-OCRv5. Original reading uses SightLine’s own model.

Cantonese uses a licensed medicine-name dictionary and a limited set of label phrases. Unmatched names are refused. The Cantonese wording has not been reviewed by a native speaker.
